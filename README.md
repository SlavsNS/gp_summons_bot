# 🤖 Telegram-бот для моніторингу повісток Офісу Генерального прокурора

Автоматизована система моніторингу офіційного розділу Офісу Генерального прокурора України:
[Повістки про виклик, повідомлення про підозру та відомості щодо здійснення спеціального досудового розслідування](https://www.gp.gov.ua/ua/categories/povistki-pro-viklik-ta-vidomosti-pro-zdijsnennya-specialnogo-dosudovogo-rozsliduvannya).

---

## 🌟 Можливості бота

1. **Цілодобовий фоновий моніторинг:**
   - Автоматична перевірка публікацій на сайті ОГП кожні 15 хвилин (інтервал налаштовується).
   - Миттєве push-сповіщення в Telegram, якщо опубліковано повістку на особу зі списку спостереження.
2. **Розумний морфологічний пошук (українська мова):**
   - Прізвища в повістках зазвичай стоять у родовому відмінку (наприклад: *Гавриленка*, *Подольської*, *Шевченка*, *Коваля*). Бот автоматично розпізнає всі відмінки та ініціали завдяки морфологічному аналізатору `pymorphy3`.
3. **Прямі посилання та документи:**
   - Бот надає пряме посилання на публікацію ОГП та кнопку для завантаження оригінального PDF/документа повістки.
4. **Миттєва разова перевірка:**
   - Можливість перевірити будь-яку людину прямо зараз через кнопку меню або команду `/check`.
5. **Зручний інтерфейс користувача:**
   - Головне меню з кнопками, перегляд списку спостереження, видалення в один клік.

## 📱 Команди та використання в Telegram

| Команда | Опис |
|---|---|
| `/start` | Запуск бота та виклик головного інтерактивного меню |
| `/add <ПІБ>` | Додати особу на моніторинг (наприклад: `/add Шевченко Тарас Григорович`) |
| `/list` | Переглянути список відстежуваних осіб з кнопками швидкого видалення |
| `/check <ПІБ>` | Миттєва перевірка за базою повісток без додавання до списку |
| `/status` | Статус моніторингу, час останньої перевірки та статистика |
| `/help` | Детальна інструкція |

## 📁 Структура проєкту

- `bot.py` — головний файл запуску бота (aiogram 3).
- `scraper.py` — асинхронний парсер сайту `gp.gov.ua` (пошук, свіжі публікації, витяг посилань на PDF).
- `matcher.py` — інтелектуальний морфологічний аналізатор українських імен та відмінків.
- `monitor.py` — фоновий сервіс періодичної перевірки та розсилки сповіщень.
- `database.py` — локальна база даних SQLite (зберігання списку спостереження та історії повідомлень).
- `handlers/` — обробники команд, інлайн-кнопок та станів FSM.
- `run.bat` — скрипт швидкого запуску для Windows.
